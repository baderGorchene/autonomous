# BookSlot

A dead-simple $19/month booking page for local service businesses (salons, clinics, tutors, mechanics, coaches) who currently manage appointments via WhatsApp chaos.

## Features
- Owner signup and service/availability setup
- Public booking page with multi-lingual support (English, Arabic, French)
- Time slot availability engine
- Email and WhatsApp notifications
- Dashboard with analytics and upcoming bookings
- Stripe subscription monetization
