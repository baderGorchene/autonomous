# BookSlot

A dead-simple $19/month booking page for local service businesses (salons, clinics, tutors, mechanics, coaches) who currently manage appointments via WhatsApp chaos.

## Features
- Owner signup, dashboard, and service/availability setup.
- Public shareable booking page (`/book/{username}`).
- Automated WhatsApp and Email notifications.
- Bilingual support (English + Arabic/French).
- Subscription and free tier management via Stripe.
